# Stroke-order data

Character stroke data for Manabi's drawing pad ([Hanzi Writer](https://github.com/chanind/hanzi-writer), MIT).
Files are named by Unicode code point (`6c34.json` = 水). Generated by `tools/gen-stroke-data.mjs`;
do not edit by hand.

- `zh/` — from [hanzi-writer-data](https://github.com/chanind/hanzi-writer-data) 2.0.1, derived from
  [Make Me a Hanzi](https://github.com/skishore/makemeahanzi), which is derived from the Arphic PL KaitiM GB
  and Arphic PL UKai fonts. Licensed under the Arphic Public License (`licenses/ARPHICPL.txt`).
- `ja/` — from [hanzi-writer-data-jp](https://github.com/chanind/hanzi-writer-data-jp) 0.0.1, derived from
  [AnimCJK](https://github.com/parsimonhi/animCJK) © 2016–2019 François Mizessyn (itself derived from
  Make Me a Hanzi). Licensed under the GNU LGPL v3 or later and the Arphic Public License
  (`licenses/LGPL.txt`, `licenses/ARPHICPL.txt`, `licenses/COPYING-ja.txt`).
